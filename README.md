Landing page interaktif untuk toko fiktif pakaian gym dan streetwear **ARCLIFT**.

## Teknologi
- HTML5 semantik
- CSS3 (Flexbox, Grid, media query, efek hover)
- JavaScript (event handling dan manipulasi DOM)
- Bootstrap 5.3.3 (form pendaftaran member)

## Fitur
1. Menu hamburger di layar HP
2. Countdown drop koleksi
3. Filter produk berdasarkan warna
4. Tambah ke keranjang dengan notifikasi
5. FAQ accordion
6. Validasi form newsletter
7. Form member Bootstrap (Nama, Alamat, Kota, Hobi) dengan validasi

## Cara Menjalankan
Buka file `index.html` langsung di browser.
